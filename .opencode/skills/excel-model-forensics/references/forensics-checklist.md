# Forensics Checklist

1. Identify workbook and confirm source path.
2. Load formulas and cached values separately.
3. Map sheet dimensions and role classification.
4. Extract cross-sheet dependencies.
5. Identify formula/hardcoded mixed columns.
6. Investigate targeted anomalies with dedicated scripts.
7. Document evidence with cell references and formula text.
8. Propose implementation/tests/validation follow-ups.
