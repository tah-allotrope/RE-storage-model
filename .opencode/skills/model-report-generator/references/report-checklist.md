# Report Checklist

1. Confirm model output dictionary contains required KPI keys.
2. Confirm `_hourly_df` and `_lifetime_df` are available.
3. Confirm reference JSON is optional and gracefully handled.
4. Generate charts as inline base64 images.
5. Keep styles inline in a single `<style>` block.
6. Validate output in browser.
7. Validate print preview for pagination/readability.
