06 / Limitations / Second-Best Alternative

Limitations / Second-Best Alternative

  • Execution time: Full workbook generation runs ~35 pipeline runs (1 default + 4 scenarios + ~30 sensitivity). Expected 5-10 minutes. The slow test is marked @pytest.mark.slow to exclude from default runs.
  • No caching: Physics stage is identical across all runs but is recomputed each time. Future optimization could cache physics results and only re-run settlement/financial.
  • No progress bar: The script logs progress but doesn't show a visual progress indicator. Should be added for user experience.
  • Second-best alternative: Could have used click instead of argparse for a richer CLI experience. Not chosen because argparse is in the standard library and sufficient for this use case.
