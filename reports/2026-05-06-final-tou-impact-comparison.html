01 / Executive Summary

Executive Summary

What We Compared

Two independently-built TOU Impact sheets inside the same PV+BESS model were audited against Vietnam's Decision 963 regulatory ground truth and first-principles arithmetic.

The Bottom Line

File C is the recommended base because it provides scenario analysis, 20-year lifetime projections, NPV, and model-update guidance — all essential for PPA pricing and investor presentations. However, File C's BESS impact must be corrected: it assumes 40 % of BESS peak discharge occurs in the 09:30–11:30 morning block, but the Cal. sheet shows 0 kWh of morning-peak discharge. File G's revaluation approach (+$101 BESS impact) is arithmetically faithful to the current dispatch.

Key Numbers

  • Solar revenue loss (both files): ~22,310 USD/yr ~12.7% loss — independently verified.
  • BESS impact — File G (revaluation): +101 USD/yr.
  • BESS impact — File C (base case): -4,591 USD/yr — incorrect premise.
  • NPV of revenue loss — File C: -345,266 USD at 9.3 % discount.

Critical Caveat

Neither file re-runs the BESS dispatch optimizer for the new TOU windows. Both are "what-if" overlays. The true BESS behavioral impact requires updating Cal.!E and re-solving dispatch — a Phase 6 follow-up.

02 / Background & Objective

Background & Objective

On 22 April 2026, Vietnam's Ministry of Industry and Trade issued Decision 963/QĐ-BCT, replacing the split morning+evening peak window (09:30–11:30 and 17:00–20:00) with a single consolidated evening peak (17:30–22:30). This change eliminates the morning-peak premium for solar generation and collapses BESS arbitrage from two cycles to one.

Two analysts built competing TOU Impact sheets inside the same base model:

  • File G — Compact (36 rows), array-formula-driven, revalues the existing hourly dispatch without rerunning it.
  • File C — Comprehensive (108 rows), 8-section analytical breakdown with base/worst cases, lifetime projections, and financial KPI impacts.

The objective was to determine which sheet is more accurate, complete, and aligned with the regulatory change, and to produce a canonical impact analysis for PPA pricing decisions.

04 / Assumptions & Constraints

Assumptions & Constraints

Key Assumptions

  • Both files use the same hourly load/generation profiles from Cal. (8,760 hours, 2024 timestamps).
  • Tariff rates (22kV industrial): Normal = 1,275 VND/kWh, Peak = 2,182 VND/kWh, Off-Peak = 859 VND/kWh.
  • FX rate = 26,000 VND/USD.
  • Old TOU windows in Cal.!E: Peak = Mon–Sat 09:30–11:30 + 17:00–20:00; Off-Peak = 22:00–04:00.

Constraints & Limitations

  • openpyxl reads cached values but cannot execute Excel array formulas (File G).
  • Neither file re-optimizes BESS dispatch for the new TOU — both are overlay analyses.
  • Hourly resolution cannot perfectly represent 17:30 and 22:30 half-hour boundaries.
05 / Methodology

Methodology

The comparison progressed through five phases:

  1. Regulatory Window Verification — Extracted old/new window definitions from both sheets and cross-checked against Decision 963 and the research brief.
  2. Solar Revenue Impact Validation — Computed an independent solar impact from Measures data and tariff rates, then traced both files' figures.
  3. BESS Revenue Impact Validation — Extracted actual BESS discharge-by-hour from Cal. to test File C's 40 % morning-peak attribution and File G's revaluation logic.
  4. Lifetime & NPV Audit — Verified File C's 20-year escalation, geometric series totals, and NPV using closed-form growing-annuity math.
  5. Scoring & Winner Declaration — Built a weighted scoring matrix across ten dimensions, declared a conditional winner, and listed specific corrections.

06 / Phase-by-Phase Analysis

Phase-by-Phase Analysis

Phase 1 — Regulatory TOU Windows

Both files state the old and new windows correctly. File G's "Tariff Bands Applied" (rows 28–30) and File C's Section 1 (rows 5–10) match the research brief exactly:

  • Old Peak: Mon–Sat 09:30–11:30 + 17:00–20:00
  • New Peak: Mon–Sat 17:30–22:30 only
  • New Off-Peak: All days 00:00–06:00

Cal.!E sampling confirmed the old flags: weekday hours 0–3 = O, 4–9 = N, 10–11 = P, 12–16 = N, 17–19 = P, 20–21 = N, 22–23 = O. Sunday hours 0–3 = O, 4–21 = N, 22–23 = O (both files treat Sunday off-peak as 22:00–04:00).

Verdict: Both pass. Neither resolves half-hour granularity, but both acknowledge it.

Phase 2 — Solar Revenue Impact

Independent calculation from Measures:

639,534 kWh × (2,182 − 1,275) ÷ 26,000 = 22,309.90 USD/yr

  • File G reports -22,312.51 USD/yr (delta) — within $3 (0.01 %), immaterial.
  • File C reports -22,310 USD/yr — matches exactly.

File G's old revenue (175,586.16 USD) and File C's old peak revenue (53,672 USD) both reconcile to first principles. File G shows 0.16 MWh shifting to off-peak (negligible, <0.01 %).

Flag: File G's partial-year "Post-Apr 22" impact (-15,881.27 USD) does not scale cleanly from the annual figure using 254/365 (-15,527.06 USD). A ~$354 discrepancy exists.

The BESS never discharges during 09:30–11:30. The dispatch is entirely evening-weighted (17:00–20:00 old peak).

File G holds dispatch fixed and revalues each hour under new rates. Result: +101 USD/yr. This is arithmetically correct for the current dispatch profile.

File C assumes 40 % of peak discharge (131,615 kWh) was in the morning block. Because actual morning discharge is zero, both its base case (-4,591 USD) and worst case (-11,046 USD) are wrong. They describe a revenue loss that does not exist in the current dispatch.

Secondary flag: File C's "afternoon/evening peak" old-revenue figure (19,661 USD for 197,422 kWh) implies an effective rate of ~2,588 VND/kWh, well above the stated 2,182 VND/kWh. This is an internal inconsistency.

Verdict: File G wins on BESS accuracy. File C's BESS section must be rebuilt using actual dispatch data, not a theoretical 40 % split.

Phase 4 — Lifetime Projections & NPV

File C provides a full 20-year escalated projection (5 % p.a.) and NPV at 9.3 % project IRR. Independent verification:

  • 20-year solar total: -737,704 USD (model) vs -737,701.44 USD (independent) — matches.
  • 20-year BESS base total: -151,806 USD (model) vs -151,805.80 USD (independent) — matches.
  • NPV factor at 9.3 %: 12.834697 → solar NPV -286,342.08 USD (model -286,342 USD) — matches.

Using a 10 % discount rate (target equity IRR from Assumption) instead of 9.3 % changes the total NPV from -345,266 USD to -325,827.17 USD (~5.6 % lower loss). File C's choice is non-standard but defensible.

File G gap: No lifetime projection, no NPV, no IRR impact. This is a material omission for investor-facing analysis.

Winner: File C (Conditional)

File C scores higher overall because it supplies the lifetime, NPV, scenario, and guidance content required for a production PPA decision. The condition is non-negotiable: its BESS impact must be corrected to reflect the actual zero morning-peak discharge observed in Cal.. Until that fix is made, File C's total impact figures (-26,901 USD base, -33,356 USD worst) overstate the revenue loss.

File G is the more trustworthy source for the current-dispatch BESS impact and should be used as the arithmetic reference when rebuilding File C's BESS section.

Error List — File G

  • Partial-year adjustment (F7): -15,881.27 USD does not reconcile to 254/365 scaling of the annual impact (-15,527.06 USD). Check day-count basis or formula.
  • No lifetime / NPV: Omitting 20-year projections and NPV makes the sheet unsuitable for standalone investor presentation.
  • No scenario analysis: Only a single "current dispatch" case is provided.
  • No model-update guidance: Missing instructions for updating Cal.!E or BESS strategy parameters.

Error List — File C

  • BESS morning-peak attribution (Section 3, rows 34–35): Assumes 131,615 kWh (40 %) of BESS peak discharge occurs in 09:30–11:30. Cal. data shows 0 kWh in that block. Base-case loss (-4,591 USD) and worst-case loss (-11,046 USD) are both incorrect for current dispatch.
  • BESS afternoon/evening peak old revenue (B33): 19,661 USD for 197,422 kWh implies an effective rate of ~2,588 VND/kWh, inconsistent with the stated 2,182 VND/kWh.
  • Discount rate choice (Section 6): Uses 9.3 % project IRR for equity NPV. Standard practice is to discount at cost of equity or target IRR (10 % per Assumption). Difference is ~19,439 USD.
  • No partial-year adjustment: Reports full-year impacts only; omits 2026 P&L forecasting.

09 / Risks / Open Questions

Risks / Open Questions

Major Risks

  • Behavioral gap: Neither file models how the BESS would dispatch under the new TOU. The true impact could differ materially if the optimizer shifts charge timing.
  • Half-hour error: Integer-hour approximation misallocates ~30 minutes of peak/normal transition (17:00–18:00 and 22:00–23:00). Estimated error <1 % of revenue impact.
  • Discount rate credibility: Using project IRR (9.3 %) for equity NPV may understate the loss to equity investors. At 10 %, the NPV shortfall is ~$19,400 lower.

Open Questions

  • Will MOIT issue revised Decision 14/2025 multipliers for the new windows, or simply remap existing multipliers?
  • Does the BESS dispatch optimizer in the VBA-free model actually function, or is the current profile hard-coded?
  • Should the partial-year adjustment be standard for 2026 budget impact reporting?
