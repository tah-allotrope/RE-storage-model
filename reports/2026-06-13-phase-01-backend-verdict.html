Phase Report · GAP-01 · PHASE-01

Backend Assessment Verdict

Expose the model's existing Go/No-Go recommendation through the web API. assess_project() already turns KPIs into a GO / CAUTION / NO-GO verdict with per-metric PASS/MARGINAL/FAIL status — but the Cloud Function response never carried it. This phase wires the verdict into serialise_results() so both run paths emit it, with a threshold-override seam left for the deferred PHASE-03.

02 · Logic Flow

Where the verdict is computed

flowchart LR A[POST /api/run-json or /api/run-excel] --> B[run model pipeline] B --> C[serialise_results kpis dict] C --> D{assess_project kpis, thresholds} D -->|all PASS| E[GO] D -->|any FAIL| F[NO-GO] D -->|else| G[CAUTION] E --> H[serialise_verdict -> JSON] F --> H G --> H H --> I[response: kpis + verdict + series]
03 · Math / Algorithm

The banding rule (reused verbatim from the model)

Each metric is scored against a threshold with a marginal band; the overall verdict is the aggregate. No new math was introduced — the phase reuses assess_project so the web verdict can never diverge from the Excel workbook's own verdict logic.

MetricDefault hurdlePASSMARGINALFAIL
Equity IRR≥ 12%≥ hurdle≥ 80% of hurdlebelow band / missing
Min DSCR≥ 1.2≥ covenant≥ 90% of covenantbelow band / missing
NPV≥ $0≥ floor≥ floor − $1Mbelow band / missing
Simple Payback≤ 15 yrs≤ maxwithin marginal bandexceeds / missing

Aggregate: all four PASS → GO; any FAIL → NO-GO; otherwise → CAUTION. A missing/NaN metric (e.g. simple_payback_years = None) safely degrades to FAIL rather than raising.

06 · Limitations / Alternative

What this phase deliberately does not do

Limitations

  • Verdict is invisible to users until PHASE-02 renders it (this phase is API-only)
  • Thresholds are fixed defaults; user editing is deferred (PHASE-03)
  • Scenario-comparison and sensitivity sub-views do not yet carry verdicts

Second-best alternative (rejected)

  • Compute the verdict client-side in TypeScript
  • Rejected: would duplicate tested Python banding logic and risk drift from the Excel workbook verdict
