03 / Math / Algorithm Used

Math / Algorithm Used

No new math — orchestration and a categorical comparison:

  • Categorical sensitivity: tariff_mode isn't a numeric sweep, so run_tariff_mode_comparison runs the full pipeline exactly twice (1C, 2C) and reports delta[k] = 2C[k] − 1C[k] for the headline KPIs (IRR, NPV, DSCR, grid savings, demand-charge savings).
  • Sheet fan-out: topologies × tariff_modes assessment/comparison sheets, suffixed (e.g. "Onsite, 2C") only when more than one mode is requested.

06 / Limitations / Second-Best Alternative

Limitations / Second-Best Alternative

  • The Comparison sheet shows one tariff mode per sheet (suffixed). The plan floated a single 16-column matrix (topology × mode × PPA option); kept it as stacked per-mode sheets to avoid an unreadable, over-wide sheet (plan RISK-03-02).
  • Sensitivity runs under the first/default tariff mode only — the dedicated run_tariff_mode_comparison is the categorical artifact, kept separate from the numeric tornado sweeps.
  • --tariff-mode both with --topology both and 4 PPA options is ~16 pipeline runs (several minutes) — acceptable for a one-shot client deliverable (plan RISK-03-01).
