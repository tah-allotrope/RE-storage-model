03 / Math / Algorithm Used

Math / Algorithm Used

Pure data extraction and unit conversion — no solver:

  • Voltage tiering: tier = 110 kV if voltage ≥ 100 else 22 kV; target option key = "{tier}-2-component".
  • Ca conversion: CaUSD/kWh = CaVND/kWh / exchange_rate_USD_VND (e.g. 1275 / 26000 = 0.04904).
  • Cp: returned unconverted in VND/kW/month, matching the unit calculate_annual_demand_savings expects.

06 / Limitations / Second-Best Alternative

Limitations / Second-Best Alternative

  • The fixture's retail_tariff_matrix shape differs from the plan's assumed flat keys — it's a tariff_options list keyed by voltage_level. The loader matches on the voltage tier, ignoring the active flag (mode is the explicit switch).
  • Excel Ca-rate selection rides on the pre-existing load_tariff_rates_from_cells Ca-label support rather than a new function — fewer moving parts, but it depends on a real 2-component workbook to exercise (none in-repo, so covered via synthetic openpyxl fixtures).
  • Second-best alternative: a dedicated TwoComponentTariff dataclass. Rejected for now — a tuple return keeps the loader symmetric with the existing dict returns and avoids a new type for two values.
