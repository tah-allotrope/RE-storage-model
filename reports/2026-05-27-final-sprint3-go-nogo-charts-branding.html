01 / Executive Summary

Executive Summary

What we built

Three new modules and integrated them into the existing workbook pipeline:

  • Assessment logic interprets equity IRR, DSCR, NPV, and payback against configurable hurdle rates, producing GO / CAUTION / NO-GO verdicts.
  • Chart generator creates matplotlib PNGs for average-day dispatch profiles, DSCR trend lines, and annual revenue breakdowns.
  • Brand system applies Allotrope green headers, Calibri fonts, conditional color fills, and a confidentiality footer.

Why it matters

Before Sprint 3, the workbook contained raw data but required manual interpretation. Now it delivers:

  • Instant readability — color-coded verdicts tell the story in seconds.
  • Visual credibility — embedded charts make dispatch and DSCR tangible.
  • Brand consistency — every sheet looks like it came from Allotrope Ventures.
02 / Background & Objective

Background & Objective

Sprints 1 and 2 built the data foundation: Excel export with payback metrics, onsite/offsite topology, and detailed proforma tables. The gap analysis identified three remaining polish layers needed before the workbook could be shown to clients:

  1. GAP-03: Go/no-go logic — automated interpretation of KPIs against hurdle rates.
  2. GAP-05: Dispatch charts — visual profiles of solar, battery, and grid interaction.
  3. GAP-08: Client branding — professional formatting and Allotrope visual identity.

The objective of Sprint 3 was to close all three gaps and produce a client-ready workbook.

04 / Assumptions & Constraints

Assumptions & Constraints

Assumptions

  • Default hurdle rates: equity IRR = 12%, DSCR = 1.2x, max payback = 15 years, NPV floor = $0.
  • Marginal bands: 80% of IRR hurdle, 90% of DSCR covenant, -$1M NPV buffer, 120% of payback max.
  • Charts are embedded PNGs (matplotlib) rather than native Excel charts.
  • Pillow is available for openpyxl image insertion.

Constraints

  • Chart sizing is approximate (800x400 px) and may vary by screen DPI.
  • Calibri font falls back to sans-serif on Linux/CI environments.
  • Conditional formatting uses static cell fills, not dynamic Excel rules.
05 / Methodology

Methodology

Sprint 3 followed a three-phase integration methodology. PHASE-01 and PHASE-02 were developed in parallel because they had no mutual dependencies. PHASE-03 integrated both into the existing workbook pipeline.

Each phase used test-first development: write failing tests, implement until green, then refactor. All new code was validated against the existing 360+ unit tests to ensure zero regressions.

06 / Phase-by-Phase Analysis

Phase-by-Phase Analysis

PHASE-01: Go/No-Go Assessment

Created assessment.py with configurable thresholds and structured verdicts. Handles NaN/None gracefully. 10 unit tests cover GO, CAUTION, NO-GO, custom thresholds, and missing data.

PHASE-02: Dispatch Charts

Created charts.py with three matplotlib generators. Uses Allotrope palette, Calibri font, 8x4 inch figures. 6 unit tests verify PNG creation from synthetic data.

PHASE-03: Branding + Integration

Created styles.py with brand constants. Refactored excel_writer.py to use green headers and add verdict/chart support. Updated orchestration script to wire everything. 3 new integration tests.

Key transition

The critical integration point was updating write_cover_sheet() to accept an AssessmentVerdict and write_assessment_sheet() to accept a list of chart paths. Both changes are backward-compatible (optional parameters).

07 / Findings & Recommendation

Findings & Recommendation

Finding 1: The go/no-go logic is robust and configurable. Marginal bands provide useful gradation between PASS and FAIL, avoiding binary oversimplification.

Finding 2: Matplotlib PNG embedding is the right tradeoff. It gives full control over complex stacked dispatch profiles with dual y-axes, at the cost of slightly larger file sizes.

Finding 3: Allotrope branding significantly improves perceived professionalism. The green header (#2E7D32) is distinctive and readable.

Recommendation: Proceed to Sprint 4 (two-component tariff) using the same workbook infrastructure. The assessment module, chart generator, and brand system are reusable surfaces.
