Function Formula Edge Cases

06 / Limitations / Second-Best Alternative

Limitations / Second-Best Alternative

  • Simple payback assumes flat EBITDA: The simple payback metric uses only Year 1 EBITDA, ignoring escalation, degradation, and OPEX growth. A multi-year payback that iterates through the full lifetime revenue/opex schedule would be more accurate but is out of scope for this phase.
  • Discounted payback returns year index, not interpolated fraction: The function returns the discrete year index where cumulative turns non-negative. Linear interpolation between years would give a more precise fractional-year answer but adds complexity.
  • Cash-on-cash uses Year 1 FCFE only: Like simple payback, this is a single-year snapshot. A multi-year average cash-on-cash would better represent the investment but requires aggregation across the full waterfall.
  • Second-best alternative: Could have used Python's numpy_financial package for payback calculations, but the formulas are simple enough to implement directly without an additional dependency.
