06 / Limitations / Second-Best Alternative

Limitations / Second-Best Alternative

  • No Excel formulas: All values are static Python-computed numbers. The client cannot modify inputs and see recalculated outputs. This is intentional per the plan (CON-001) but limits the workbook to assessment use only.
  • No chart embedding: Dispatch charts and DSCR charts are deferred to Sprint 3 (PHASE-02 of that sprint). The assessment sheet currently shows only tabular proforma data.
  • No go/no-go verdict: The Cover sheet shows raw KPIs without interpretive assessment logic. This is deferred to Sprint 3 (PHASE-01).
  • Column width estimation is approximate: The _auto_width() function uses string length, which doesn't account for font metrics. Some columns may be slightly too narrow or too wide.
  • Second-best alternative: Could have used xlsxwriter for better chart support and conditional formatting. Not chosen because openpyxl is already a project dependency and handles both read and write.
